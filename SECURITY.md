# Security

This repository is a technical demonstration, not a security-reviewed production service. Use synthetic data, local-only database exposure and your own credentials.

Report suspected vulnerabilities through the hosting platform's private vulnerability reporting feature when available. If no private channel has been enabled, first request one from the maintainer without publishing exploit details, credentials or personal data in an issue.

Before public release, the maintainer must enable a private reporting channel. If a credential is exposed, revoke or rotate it before cleaning the repository history.
