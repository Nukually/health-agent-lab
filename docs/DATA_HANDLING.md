# 演示数据处理边界

## 实际流向

浏览器将演示登录标识、消息和文件发送至当前实例后端。后端持久化会话、档案、授权和使用事件到数据库，图片功能可能使用部署者配置的 OSS。消息及相关历史会发送到配置的 LLM；启用 embedding、OCR、ASR/TTS、检索、Push 或观测后，还会产生对应外部请求。

本地数据库不代表计算全在本地。代码没有向项目维护者回传数据的默认服务地址；第三方服务商自己的留存、训练或跨境策略需由部署者核对。

## 默认配置

`.env.example` 仅含本地开发示例和占位符，关闭自动记忆处理、疗效分析、需求合并、Push、远程 tracing 和调试路由。可选知识库和医生服务没有预设地址或令牌。没有外部存储配置时不支持上传保存。

固定验证码只用于 local/dev 演示。不要将开发环境直接暴露到公网。复制示例配置后必须生成自己的 JWT secret、配置自己的模型 Key。

## 演示授权

登录说明与档案处理确认保留前后端版本和记录机制，但不提供公司服务合同，不包含关联企业数据共享、商业数据开发或训练用途授权。演示仅使用合成数据。

前端会话/档案清理和账号注销不能保证删除日志、备份或外部服务副本。公开运营前，实际运营者应完成真实的数据清单、接收方和保存期限说明，以及权利请求、撤回授权、删除、访问控制和安全评估。
