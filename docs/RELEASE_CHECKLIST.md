# 发布检查清单

- [ ] 权利人确认代码、贡献及必要文档可按 Apache-2.0 发布；第三方内容许可单独核对。
- [ ] 当前源码及拟发布的全部 Git 历史、标签和附件均完成秘密扫描和人工复核。
- [ ] 不包含真实配置、数据库、会话、日志、运营报表、公司标识、内部地址或签名材料。
- [ ] 只使用合成测试数据及可再分发素材；不附带外部知识库语料。
- [ ] `pnpm install --frozen-lockfile`、`pnpm build`、`pnpm test`、`pnpm check:publication` 均通过。
- [ ] 独立数据库的迁移及 schema 校验通过；运行时没有自动请求未配置的集成。
- [ ] H5 登录页、演示说明、数据处理说明及基本聊天 UI 已检查。
- [ ] 已审阅第三方许可证清单并保留所需署名；新增二进制包另行审查。
- [ ] 已设置私密安全报告渠道，确认发布目标、维护者信息和发布范围。

模式扫描不是“没有任何敏感信息”的证明。示例数据也要人工复核，特别是自由文本、截图和二进制内容。公开仓库、推送分支和部署服务分别需要明确操作授权。
